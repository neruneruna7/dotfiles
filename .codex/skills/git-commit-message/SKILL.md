---
name: git-commit-message
description: gitのコミットメッセージを書くときの規約とテンプレを適用する。
---

日本語で記述すること．

- 追加: 新しい機能やファイルを追加したとき
  - プレフィクス: `add`
  - `add: 追加した内容の簡単な説明． 追加した理由`
- 修正: 既存の問題を修正したとき
  - プレフィクス: `fix`
  - `fix: 修正した内容の簡単な説明． 発生していた問題`
- 改善: 既存のコードやドキュメントを改善したとき
  - プレフィクス: `update`
  - `update: 改善した内容の簡単な説明． 改善の理由`
- 削除: 不要なコードやファイルを削除したとき
  - プレフィクス: `delete`
  - `delete: 削除した内容の簡単な説明． 削除の理由`
